# Original Qiaomu Reader source

Origin: https://github.com/joeseesun/qiaomu-reader
Stable commit: 4a6e6ee1e39966f2af5d831df8b3f4c4fd387ca3 (4.9.2).
License: GPL-3.0-only; see LICENSE. The embedded Kindle writer has its own retained notices under ../vendor/kindle-azw3.

This directory preserves product UI, CSS, translations and business code. Host adapters replace Obsidian/Electron boundaries; the original working directory is not edited. Additional format parsing uses the same Foliate library as the original reader, with an adapter to the already accepted Harness reading surface.

The Chinese EPUB test fixture (Project Gutenberg 7337) retains its embedded Gutenberg license.
